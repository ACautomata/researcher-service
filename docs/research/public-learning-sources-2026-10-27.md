## B 站检索和热度：已知与未知

[B 站开放平台文档入口](https://open.bilibili.com/doc)列有账号授权、视频稿件管理、用户授权后的稿件数据等能力，也说明部分开发者能力需要身份审核。这些类别本身不能证明它提供面向任意公开视频的关键词搜索、全站播放量读取或本产品可用的完整正式契约。

本轮没有找到并核验适用于本产品的 B 站**全网关键词发现和公开视频热度字段**的官方公开 API 契约；这不等于断言不存在。字段覆盖范围、权限、申请资质、配额、时效、费用、展示权与协议均待官方确认。非官方脚本、网页中推测出的接口或第三方封装不能当作正式支持证据；本次未登录、抓用户数据或试探私有接口。若通过合规搜索服务发现 B 站链接，也应将搜索服务结果与 B 站官方热度数据区分，不能将搜索排序称为播放量。

热度可作为视频候选的补充信号；仅在来源、含义、采集时间和展示权限可核验时显示指标。不同平台的观看量及统计口径不应直接比较，更不能以高播放量替代内容可靠性。

## 对首版的建议

1. 先围绕具体问题搜索可读的中文官方文档和高校课程页面；英文权威资料按需要补充。保留原始链接、标题、机构、日期或版本以及实际找到的证据片段。
2. 来源权威性按资源逐条说明依据：例如软件项目官方文档、课程页所标示的授课机构、学校官网指向的视频；不要将平台收录本身等同于作者身份认证。
3. 正文或可靠字幕可读取时，才用实际内容支撑具体推荐理由；只有标题、简介或搜索摘要时，仅称“可能相关，尚未核验内容”，不要生成视频具体讲解内容或时间戳。
4. 保留课程页与视频页的区别：目前这两门 MOOC 只验证到课程介绍，不能承诺直接跳至对应知识点的播放位置。登录、付费、字幕、跨地区可访问性均按实际验证结果展示；未知就标为未知。
5. 将以上来源用于建立小规模测试问题集，例如“矩阵特征值有什么意义”和“Vue 的响应式是什么”，分别核对链接可访问性、机构归属、问题相关性与推荐依据。先验证搜索服务对这些原站的真实覆盖，再决定是否扩展来源。
