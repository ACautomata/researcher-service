# 超星课程资料检索第一版

2026-10-26 用户确认：先按对方提供的资料 HTTP 接口实现可用版本，暂不要求满足全校、跨专业课程检索；知识点功能暂缓。此版本范围覆盖既有规格中的全库验收要求，后者保留为后续目标。

## 使用方式

先在账号设置绑定本人超星账号，然后在对话中执行：

```text
/course-search --course-id <课程ID> --class-id <班级ID> <资料名称关键词>
```

课程与班级 ID 来自本人已加入课程的页面；页面 URL 的 `courseid`、`clazzid` 分别对应请求中的 `courseId`、`classId`。服务端固定使用学生身份 `ut=s`，权限仍由超星验证。课程发现尚无接口，首版不自动抓取网页或猜测 ID。

自然语言推荐优先使用 `target=resources`。HTTP 模式下，未指定目标及旧的 `target=all` 请求也只查询资料，并明确说明知识点查询暂缓；显式 `target=topics` 和既有命令继续保留兼容，但不参与默认推荐，菜单提示首版暂缓。

## 接口与结果

- GET `https://api.chaoxing.com/openapi/coursedata/searchCourseDataJson`，沿用本人 OAuth Bearer token。
- 参数为 `courseId`、`classId`、`ut=s`、`dataName`、`pageNumber`、`pageSize`。
- 按名称分页查询，过滤文件夹，关键词零命中重试后以空 `dataName=` 核对；处理和展示上限沿用既有实现。
- 展示资料名称、资料 ID 和课程 ID；课程名称缺失时明确显示 ID。
- 文件直达链接 `url` 仅使用接口实际返回的安全 HTTPS 地址；另提供经本人浏览器验证的官方课程资料列表入口 `courseDataUrl`，由本次查询的课程/班级 ID 生成，不包含个人签名或令牌。不能将 `objectId` 拼接为未经验证的下载地址，不能声称读过正文。
- 手动查询在结果中展示可点击的“前往课程资料”，自然语言工具也返回该入口并说明访问方式。用户需在当前浏览器登录本人超星账号，进入后按文件名搜索或进入对应文件夹，再点击资料预览。课程资料页不是单份文件的直达链接。
- 使用者必须有对应课程资料权限；全量课程目录、跨课程发现、正文问答及下载链接不作为首版完成条件。

## 本次真实调用

通过线上管理台的 POST `/api/v1/integrations/chaoxing/learn` 调用现有资料适配器，复用本人绑定，不导出令牌。

- 对方截图中的课程/班级参数：返回 `code=90003`、`httpOperation=resources`、`httpFailureReason=business_rejected`。仅记录业务拒绝，不推断具体拒绝原因。
- 在本人超星课程列表取得已加入课程的真实参数后，关键词“可视”、`target=resources`：返回 `code=0`，4 条资料，包括 DOCX、PDF 和视频目录；均未返回可访问链接。个人课程参数及学生作品名称不写入仓库。
- 同一课程使用不存在的检索词：返回 `code=0`、`resources=[]`；零命中核对路径未误报为接口失败。
- 该真实成功验证现有线上接口和本人课程权限；本地新增的默认目标收敛及菜单提示需发布后才在线上生效。

## 资料打开路径实测（2026-10-26）

用户要求直接进入本人超星继续查资料访问方式。通过本人课程的资料菜单、教材与实验文件夹查看实际页面：

- 官方课程资料页为 `https://mooc2-ans.chaoxing.com/mooc2-ans/coursedata/stu-datalist?courseid=<课程ID>&clazzid=<班级ID>&ut=s`。仅保留这三个参数、去除 `cpi`、`stuenc`、`t` 后，当前已登录浏览器仍可加载课程资料列表。
- 从上述简化入口进入实验文件夹、点击命中的实验 DOCX，官方预览实际加载出六页文档，首屏显示实验指导书及正文图片。该结果验证“课程资料入口 → 定位资料 → 点击预览”可用，未宣称单份文件一键直达。
- 官方云盘预览采用含 `nonce`、`timestamp`、`signature` 等参数的地址。不带签名参数的文件路径返回参数不完整，不能直接从 `objectId` 生成稳定预览链接，也不能复制本人临时签名到检索结果。
- 官方 `coursedata/downloadData` 页面链接会跳转到带临时参数的文件服务；本次独立打开命中 DOCX 的下载地址后，文件服务返回 403。未将此地址作为可用下载链接提供。
- 资料页的 `dataName` URL 参数未起到筛选作用，因此生成的入口不附加虚假的文件名筛选参数。

以上网页验证使用本人浏览器的超星登录态；平台 OAuth 绑定不能替代浏览器超星登录。本地新增 `courseDataUrl` 及可点击展示尚未发布上线。资料搜索的范围与权限保持原有约束。
