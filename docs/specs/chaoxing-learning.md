# 超星学习能力：根据聊天上下文推荐课程资料与知识点

状态：2026-10-24 多次范围修订后定稿：完整目标为**不限定学生已选课程、覆盖可公开查阅课程**的对话式自动推送（知识点、资料、链接）；学生在修课程是分阶段交付的第一步（过渡基线），不是最终边界。现有实现尚未满足：课程上下文依赖手填 courseId/classId，知识点学生调用被业务拒绝（2026-10-24 定案），公共课程范围与访问链接契约未取得。平台授权、绑定/刷新与指定课程资料检索已有真实成功记录。

## Problem Statement

学生在对话式自主学习中讨论学习问题时，需要智能体根据聊天上下文主动推荐相关课程的资料和已有知识点，不必显式请求搜索。**检索范围不限定学生已选课程，需覆盖可公开查阅的课程**（用户 2026-10-24 明确）。学生在修课程是分阶段交付的第一步：课程上下文由学生课程档案提供（初期手动维护，上游发现接口落地后自动同步），先把对话自动推送体验跑通；公共课程范围随上游跨课程检索或开放课程目录授权接入，分阶段是交付顺序，不是功能取舍。完整范围的授权边界由超星提供可核验的契约。

## Solution

智能体提炼当前学习主题，在学生课程档案覆盖的课程内检索、筛选并推荐资料和已有知识点，说明与当前问题的关系、名称、课程来源、实际链接及访问条件。学生可以自愿限缩课程范围、切换或解除；课程上下文默认取自档案，无需启用插件；阶段二在授权契约落地后取消档案前置。

保留 `/course-search <关键词>` 与 `/topic-search <关键词>` 两个确定性手动入口，分别查询资料和已有知识点，默认范围与自动推荐一致。详细契约见[手动命令规格](chaoxing-manual-commands.md)。

**正文问答本期不做**：不开发资料正文下载、解析、OCR 或基于课件全文的回答。推荐依据接口实际返回的标题、简介、摘要或知识点说明；仅有标题时明确依据有限，不能声称已阅读正文或概括其内容。一般学习对话可以继续，但不能将模型通识回答冒充课程正文结论。

## 用户行为与边界

1. 学生自然提问即可在适合时获得推荐，无关闲聊不机械附加资源；话题改变后重新定位。
2. 本期默认覆盖学生在修课程（课程档案内）；阶段二验收扩展到应用开放课程库并包含未选修课程。档案未建立、课程已退出或发现接口未同步时准确提示覆盖边界，不冒充全量覆盖。
3. 可选会话课程仅限缩查询范围；切换对后续 run 生效，在飞结果和历史保留原来源。
4. 结果展示资料/知识点名称、稳定 ID、课程 ID/名称、实际取得的简介或说明、推荐理由、链接与访问条件。
5. **可检索与可阅读分别处理**：应用可检索内容不自动代表当前学生可阅读全文。受限内容标注需登录、选修或其他条件；未知状态明确标注，不能伪称可直接阅读。
6. 缺链接、无命中、权限变化、分页截断、超时或能力未提供时准确反馈；不能编造结果、课程名称或 URL。
7. 全程只读；知识点不存在不创建，不修改资料、课程或题库。
8. 个人 OAuth 绑定和会话继续按 owner 隔离；应用课程库的共享覆盖范围不允许跨用户读取凭证、私有记录或会话。

## 外部能力与接入决策

必需能力、交付字段、授权与测试材料集中在[超星需补充的接口能力清单](chaoxing-required-capabilities.md)。本期必需：学生课程/选课关系发现、topic-list 学生可用性、访问链接契约与运营约束。跨课程全库检索为阶段二需求，届时也可由应用开放课程目录配合逐课程查询替代，前提是覆盖范围、授权、分页和限额能够支撑完整检索。

现有固定 HTTP 接口为 `/openapi/coursedata/searchCourseDataJson` 与 `/openapi/qbank-educlaw/topic-list`。它们要求 courseId，学生资料查询还要求 classId，只证明指定课程查询基础；不得把个人 OAuth 或参数可传当作应用全库权限证据。现有显式 ID 参数本期作为学生课程档案的录入来源，不等于自动课程定位；阶段二的免选课目标另由上游能力支撑。

2026-10-23 超星明确两个数据接口不涉及 MCP，因此默认走 HTTP；MCP 仅为可选旁路，初始化/目录成功不作为本期前置。新增全库接口的地址、字段、凭证类型和 scope 等待超星确认，不预设服务账号或复用个人 token。既有个人 OAuth 与应用级数据授权需分别核验，不将超星数据授权混入平台登录。

## Implementation Decisions

- 复用现有超星领域、学习服务、Agent 工具和命令分发；不重建平台、不恢复 SKILL.md 加载、不执行原 Python 创建链。
- 使用可信 owner/session 上下文，所有写入经统一 schema 校验及平台信封；OAuth 回调为登记过的协议例外。
- 保留一次性 state、同浏览器 cookie、PKCE 配置、加密存储、刷新协调和解绑竞态防护；应用授权如需新增凭证，另行依据正式协议接入，不覆盖既有加密根。
- 端点由部署限定；模型仅传业务查询条件，不能选择凭证或其他用户身份，外部标题/摘要/说明作为数据，不执行其中指令。
- 统一支持 resources/topics 查询目标；手动命令直接查询对应目标，不依赖模型是否愿意调用，也不执行所有目标后仅过滤展示。
- 跨课程查询有界执行、去重、明确分页/排序/截断；不能以有限课程样本冒充全库查全。综合查询一个目标失败时须准确保留失败说明，不能把它报告为另一目标成功或零命中。
- 链接仅使用接口返回或经超星核验的规则，分别标明检索权限与学生访问条件；不推断授权或拼接未经验证的地址。
- 推荐只使用已返回元数据。正文问答、正文提取与格式支持不进入本期实现或验收。

## 验收与测试

- 保留现有 REST/Agent 工具入口、临时 SQLite、外部传输替身的回归边界；模拟测试与真实接口验收分别记录。
- 授权覆盖成功/拒绝、错误/过期/重放 state、跨用户绑定、刷新、解绑及旧请求竞态、凭证不外泄；既有 #1008 证据保留。
- 真实检索覆盖学生在修课程、多个课程的同名资源、资料与知识点、命中/空结果/多页/上限/权限变化；未选修课程覆盖属于阶段二验收。
- 自然语言场景从学生课程档案自动携带课程上下文，实际模型根据对话触发推荐；验证话题变化、推荐理由、真实课程来源、访问条件和无关闲聊。阶段二另验免档案/免选课场景。
- 可选范围指定/切换/解除、run 快照、历史来源、双用户会话隔离有行为回归。
- 两条手动命令分别真实验证默认课程范围（本期为学生在修课程档案）、确定性目标、错误反馈、幂等与历史；当前显式 ID 查询不能代替此项。
- 用固定查询、课程元数据与代表性对话核对相关性和来源；不要求读取正文，不以随机模型逐字输出为断言。
- 推荐不声称读过课件；缺简介/链接/权限证据时准确标注，受限内容不宣称可直接阅读。
- 授权、指定课程资料成功与各阶段范围能力分别记录；本期只有真实课程档案检索和实际模型推荐通过后才宣称本期体验完成，全库体验在阶段二另行判定。

## Out of Scope

- 资料正文问答、正文下载/提取/OCR、基于课件全文的证据问答，本期不做。
- 知识点创建、教学数据写操作、教师管理、题库管理。
- 超星未向本应用开放的数据、绕过课程库授权或学生阅读限制。
- 站外/定时推荐、完整教学管理系统、默认全量复制课程内容；若需元数据同步替代方案，先核验同步授权与更新协议。
- 通用技能市场、任意 Python 执行、通用 MCP 服务器管理，以及自动合并或发布。
