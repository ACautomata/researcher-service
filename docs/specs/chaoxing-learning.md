# 超星学习能力：学生授权、对话学习与自动资源推荐

状态：已确认 API/Agent 工具测试边界，功能分支实施中；真实超星协议与数据能力待授权联调。

## Problem Statement

学生希望在天津大学科研智能体平台中通过对话学习本人课程，并获得相关资料、知识点和学习链接。当前平台没有超星绑定、基于学习话题的资源定位或超星 MCP 接入，智能体无法读取获授权的教学数据。外部提供的两个技能包是直接调用接口的脚本，不能直接装入已经退役的官方 Skill 目录。

## Solution

提供面向学生的内置学习能力。学生在账号设置完成超星绑定后即可直接对话学习，无需先选课程或显式提出检索请求。智能体根据当前学习话题与对话上下文，在本人有权限的课程中定位相关知识点和资料，在学习回答中适时自动推荐并说明推荐理由、课程来源及可访问链接。用户可自愿限定会话课程；只有课程歧义实质影响结果时才追问。能力不要求用户在插件目录启用。

适配现有平台的提示词指导、工具注册和代码工作流，优先复用两个技能包中适用的流程与脚本。验证 MCP 与 HTTP 能力及各自授权后，为每项能力选择一条调用路径，避免重复实现。第一版只读，不执行知识点创建。缺少数据或访问权限时明确说明，不能用资料标题推测正文。令牌可刷新时自动刷新，否则引导重新绑定。

## User Stories

1. As a 学生, I want 在账号设置发起超星绑定, so that 我可以授权访问本人课程。
2. As a 学生, I want 在超星页面完成登录和授权, so that 授权过程由教学平台确认。
3. As a 学生, I want 授权结束回到平台并看到绑定结果, so that 我知道是否可以开始学习。
4. As a 学生, I want 在取消或拒绝授权时看到可理解的提示, so that 我可以决定是否重新尝试。
5. As a 学生, I want 查看绑定状态并解绑, so that 我能控制平台后续访问。
6. As a 学生, I want 未绑定时从对话获得绑定引导, so that 我知道如何使用课程能力。
7. As a 学生, I want 推荐只来自本人有权限访问的课程, so that 推荐内容实际可用。
8. As a 学生, I want 绑定后直接开始学习而不必先选课程, so that 学习过程不会被设置步骤打断。
9. As a 学生, I want 智能体根据当前学习话题自动推荐相关知识点和资料, so that 不必额外请求搜索。
10. As a 学生, I want 可选地指定、切换或解除课程范围, so that 需要时能够聚焦某门课。
11. As a 学生, I want 使用自然语言学习即可获得合适的资源推荐, so that 不必了解工具名、发出检索命令或启用插件。
12. As a 学生, I want 智能体读取相关资料正文后回答, so that 解答有课程依据。
13. As a 学生, I want 回答附资料名称、出处和可访问链接, so that 可以核对和继续学习。
14. As a 学生, I want 查询已有课程知识点, so that 可以理解知识结构。
15. As a 学生, I want 学习过程中保持课程数据只读, so that 提问不会意外修改教学内容。
16. As a 学生, I want 检索为空或证据不足时得到明确说明, so that 不会将推测当成课程内容。
17. As a 学生, I want 在正文无法取得时获知限制, so that 能区分资料推荐和基于正文的回答。
18. As a 学生, I want 授权过期时自动恢复或得到重新绑定引导, so that 知道如何继续学习。
19. As a 学生, I want 课程权限变化时停止无权访问, so that 平台遵守当前授权范围。
20. As a 学生, I want 接口超时或失败时看到准确提示, so that 可以稍后重试。
21. As a 学生, I want 本人的超星绑定和课程数据与其他用户隔离, so that 他人不能借用我的授权。
22. As a 学生, I want 学习话题或课程范围变化后既有消息仍保留原来源归属, so that 历史回答不会被错误归到新课程。
23. As a 运维人员, I want 在后端配置应用凭证和回调地址, so that 无需将秘密交给浏览器或模型。
24. As a 开发者, I want 有可重复的授权和工具集成测试, so that 不依赖真实学生数据验证回归。

25. As a 学生, I want 推荐说明它与当前问题的关系和所属课程, so that 我知道为什么值得学习。
26. As a 学生, I want 多门课程有相关内容时由智能体先定位合适资源, so that 无需逐门手动查找。
27. As a 学生, I want 只在课程歧义确实影响回答时被询问, so that 普通学习对话保持连续。

## Implementation Decisions

- 平台身份与超星绑定分离，不将超星资源授权混入现有登录 OIDC 预留字段。
- 账号设置提供绑定状态、授权入口与解绑；对话提供绑定引导；会话支持可选的课程范围提示及指定、切换、解除，不将课程选择作为使用前置条件。
- 增加超星集成领域：授权事务、加密令牌存储、刷新协调、解绑，以及远程 MCP 连接和受控的只读能力映射。
- 增加用户级绑定持久化；用户显式限定会话课程时持久化该可选范围，未限定则按当前话题检索本人获授权课程。授权事务关联发起的平台用户，具有短期有效期与一次性 state；令牌字段仅后端可读。具体表结构及错误码在实施票中遵循既有契约确定。
- OAuth 发起与状态/解绑接口归平台认证保护；回调依靠已保存的一次性授权事务确定 owner，不依赖浏览器携带 JWT，也不信任回调传入的用户 ID。交换令牌前完成 state 校验；PKCE 和客户端认证按核验后的超星协议实现。
- REST 写入参数遵循现有 schema 校验和统一信封；OAuth 浏览器跳转属于必要协议例外，需要登记 API 契约。回调跳转仅允许平台预定页面。
- 应用密钥、access token 和 refresh token 后端保管，持久化加密，日志、接口及模型结果不泄露；不默认沿用 LLM 加密根，实施时明确配置与恢复方式。
- 刷新能力按超星实际协议启用；并发刷新需协调，解绑后禁止旧请求重新写入有效绑定；失败时停止数据调用并要求重新绑定。
- MCP 地址使用部署配置限定的超星端点，不提供学生可编辑的任意服务器地址。发现工具后映射必要的只读能力，不自动将服务全部工具暴露给模型。
- 复用现有 Agent 工具装配与运行上下文，owner、session 身份来自可信运行时。学习工具作为内置能力接入，不伪装为默认启用的隐藏插件，不恢复通用 Skill 上传/执行机制。
- 学习领域服务统一负责用户授权、话题驱动的课程/资源定位、可选会话课程、权限与外部能力调用；模型只传业务查询参数，不选择其他用户身份或接触凭证。
- 默认根据当前话题从本人可访问课程定位资源，必要时解析班级上下文；学生不必提供 courseId/classId。若外部接口只支持按课程查询，由后端协调课程发现和有界查询，不把技术参数缺失转嫁为强制选课。可选会话课程只限缩范围；run 启动捕获范围，变更对后续 run 生效，历史与在飞回答保持原来源。
- 对话流程为识别当前学习话题、定位获授权课程资源、检索资料/知识点、读取所需正文、生成学习回答并适时推荐。推荐属于当前对话回复，不是定时或站外推送；资源应与当前问题相关，并附推荐理由与课程来源。话题改变后重新判断，不机械附加无关资源。资料正文作为证据处理，不能改变用户授权或工具权限。
- 资料链接采用实际接口返回或经验证的生成规则；不编造下载或课程链接。不支持的文件类型明确提示，首批支持范围以联调结果登记，不默认包含任意格式与 OCR。
- 复用并适配两个外部技能包：资料检索包的查询、分页、文件夹过滤和无结果处理；知识点包拆出只读查询，创建分支不接入。将流程适配为平台工具指导；脚本复用需通过凭证、用户隔离及结果适配验证，不直接加载原始 SKILL.md，也不默认 API Key 等同 OAuth token。MCP 已覆盖的同类功能与脚本择一接入，保留取舍依据。
- 先完成授权与 MCP 能力核验，再推进依赖真实课程列表、正文与链接的实现。缺失能力作为阻塞记录，不将不具备功能的占位实现作为验收通过。

## Testing Decisions

用户已确认的测试边界：

- 优先在现有应用 REST 与 Agent 工具调用入口验证外部行为，使用真实临时数据库，复用现有认证、会话归属与信封集成测试方式。
- 将超星视作一个外部依赖边界：测试替换 OAuth/MCP 传输与响应，保留内部授权事务、令牌持久化、课程上下文和工具映射真实执行。仅在核心装配处注入该依赖，不为每个步骤另造 mock 接缝。
- 授权覆盖成功、拒绝、过期/错误/重复 state、回调归属、刷新失败、并发刷新、解绑后停止访问及凭证不外泄。
- 用两个用户和独立会话测试无选课时的自动课程定位、可选范围持久化/解除、权限撤销、范围变化的 run 快照、越权拒绝；不只检查请求中是否出现 owner 字段。
- 工具边界覆盖协议初始化/工具列表/分页、只读映射、创建能力不暴露、资料为空、正文不可用、取消/超时、异常转译，以及返回来源和链接的课程归属。
- 前端复用现有组件与会话交互测试，验证绑定状态和引导、无需选课即可学习、可选范围指定/解除、自动推荐及其理由、错误提示、来源链接展示；不依赖像素快照或内部函数调用顺序。
- 回答质量以固定资料与问题进行集成验收，核对关键结论与引用是否受到证据支持；不锁定随机模型的逐字输出。
- 真实联调单独执行，使用获授权的测试学生及课程；不将网络和生产凭证加入默认 CI。至少验证一次绑定、不选课直接学习、自动定位资源、读取正文、回答附推荐链接、可选范围限缩及解除、解绑闭环。自动测试成功不等同远程能力已验证。
- 后端现有插件 REST 测试提供临时数据库和双用户认证先例，会话 API 测试提供归属与状态先例，前端会话交互测试提供界面驱动先例。

## Out of Scope

- 教师管理、创建或修改知识点、题库和课程资料。
- 对话之外的定时或站外推送、全量同步课程、完整教学管理系统。本人获授权课程范围内的对话自动推荐属于第一版范围。
- 恢复旧官方 Skill 目录、通用技能市场、任意 Python 脚本执行或通用可配置 MCP 服务器管理。
- 重建独立学习平台、变更平台登录方式、改造科研工作流。
- 未经验证的令牌通用性、任意文件格式支持、对正文不可用的静默降级。
- 自动合并 PR 或发布线上。
