# 超星学习能力接入：需求澄清记录

状态：第一版产品范围已确认；技术协议待联调，尚未开始功能实现。

## 已确认

- 第一版面向学生自主学习。
- 每名学生绑定自己的超星账号；平台登录与超星资源授权分离。
- 账号设置提供绑定、解绑入口；对话中未绑定时引导绑定。
- 学生绑定后直接对话学习，无需先选课；智能体根据学习话题自动定位本人获授权课程中的相关知识点和资料，并在回复中推荐。
- 手动指定会话课程是可选的范围限制，支持保存、切换和解除；仅在歧义实质影响结果时询问课程。
- 智能体按需读取相关资料正文，基于内容回答；推荐附相关性说明、课程来源和可访问学习链接。
- 第一版全程只读：查询已有知识点，不执行不存在即创建的操作。
- 对话中自然语言触发能力，不增加显式插件启用入口；不以恢复通用 Skill 加载系统为第一版目标。
- 适配现有平台工具与工作流机制，复用两个技能包的流程和适用脚本；核验 MCP 与 HTTP 授权后按能力选择调用路径，知识点创建部分不接入。
- 超星支持刷新时后端自动刷新令牌；刷新失败或授权失效时暂停课程调用并提示重新绑定。

## 当前代码事实

- 官方内容目录、read_official_skill 和旧 /research 已退役，不能通过放入 SKILL.md 直接接入。
- 平台已有插件工具与运行时端口机制；是否复用或增加内置工具接缝尚未决定。
- 当前没有已实现的超星资源授权绑定和通用远程 MCP 客户端。
- 两个外部技能包分别提供课程资料检索，以及查询或自动创建知识点的 Python HTTP 调用；不是远程 MCP 客户端。

## 已做的只读探测

- 2026-10-22：向 MCP 地址发送不带令牌的 initialize 请求，网关返回 401，WWW-Authenticate 为 Bearer。
- 尚未通过授权网关，不能判定 MCP 初始化成功或工具可用。
- 已探测的 OAuth 公开元数据路径返回 404，不能由此推断不支持 OAuth。

## 实施顺序与验收

1. 授权契约与测试准备：确认授权参数、回调登记、scope、令牌认证方式、刷新支持和测试学生课程。拟定回调为 https://researcher.acautomata.top/api/v1/integrations/chaoxing/callback，目前未实现、未登记；正式联调前验证域名与部署可达性。
2. 授权绑定闭环：实现发起授权、一次性 state 校验与平台用户绑定、回调换令牌、加密存储、状态查询及解绑。凭证仅在后端使用，错误与日志净化。验收：测试学生绑定成功，错误或重复 state 被拒绝，解绑后停止调用并清除本地凭证；远端撤销按服务支持情况处理。
3. MCP 能力核验：完成初始化与工具列表发现，登记工具参数、授权范围和读写分类。验收：真实读取获授权测试课程；确认课程/班级列表、知识点、资料正文与链接的覆盖范围。缺能力时先记录缺口，不将目录推荐当成正文问答验收。
4. 核心适配与 Agent 工具：后端按可信 owner 身份取令牌，对模型只开放必要的只读工具。底层接缝需对照现有能力装配契约设计，不通过隐藏开关绕过插件启用语义。验收：两个平台用户隔离，拒绝越权课程调用，超时/取消可收敛，创建工具不暴露。
5. 对话学习与自动推荐：按学习话题定位本人获授权课程资源，读取相关正文，在回复中给出推荐理由、来源和链接；会话课程作为可选范围持久化，支持切换及解除。验收：未选课即可获得相关推荐，话题变化后重新定位，显式范围被遵守，历史来源不变；无资料、无权限、正文不可用时准确说明，不编造内容或链接。
6. 回归与发布准备：验证授权过期、刷新失败、解绑、并发用户、课程权限变化及接口异常；完成类型检查、必要测试和审查。提交 PR 前说明 master 合并后会自动触发 CD；本澄清记录不授权自动合并或发布。

## 技术核验事项

- OAuth 授权码参数、PKCE 要求、token 客户端认证方式、refresh/revoke 支持。
- MCP transport、协议版本、会话管理和实际工具清单。
- API Key 与 OAuth access token 的关系，不默认两者可互换。
- 课程及班级发现、跨本人课程检索或后端按课程协调查询、资料正文获取、文件类型处理和学生可访问链接。
- 若正文或课程列表能力缺失，需确认替代接口或调整范围，不能默认为已满足。
- 课程切换期间在飞请求、历史引用留存和超星调用额度等细节，在相应实施任务中明确。

## 范围修正

用户明确纠正：学习中自动推荐是核心需求，强制先选课程不是第一版前置条件。早先六票草案中的“会话课程选择”应改为话题驱动的课程/资源定位，手动限缩作为可选行为；后续检索与问答验收须覆盖自动推荐。尚未发布 GitHub tickets。

本记录不包含外部凭证。接口事实经联调验证后补充；重要架构取舍形成后再记录 ADR。
