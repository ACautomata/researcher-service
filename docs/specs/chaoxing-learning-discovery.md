# 超星学习能力接入：需求澄清记录

2026-10-24 用户确认修订；现行产品范围以[主规格](chaoxing-learning.md)为准，外部依赖以[接口能力清单](chaoxing-required-capabilities.md)为准。

## 已确认

- 第一版面向学生，目标是根据聊天上下文推荐课程资料和已有知识点，不要求先选课、输入 courseId/classId 或启用插件。
- 默认检索范围为**超星向本应用开放的全部课程库**，包含未选修课程；不是仅本人课程，也不假定超星全平台无条件开放。
- 课程限缩、切换、解除是可选操作，默认自动定位跨课程资源。
- 推荐展示名称、课程来源、实际取得的简介/摘要/知识点说明、推荐理由、链接和访问条件；可检索与可阅读分别核验。
- **正文问答本期不做**，不要求正文下载、解析、OCR；不能根据标题编造正文或声称已阅读课件。
- 只读，不创建知识点；保留自动推荐和两条手动命令，不恢复 SKILL.md 加载或任意 Python 执行。
- 个人绑定与会话仍隔离；应用课程库授权与个人 OAuth 权限分别确认，不能由绑定成功推断全库数据权限。

## 当前事实

- 学生授权与刷新已有生产记录（#1008 已关闭），指定课程资料 HTTP 查询成功，知识点查询失败。
- 现有 HTTP 查询依赖显式课程/班级参数；缺应用开放课程目录或跨课程查询，尚未满足免选课全库推荐。
- 两个技能包是 HTTP 脚本：资料名称检索，以及查询不到即创建知识点；当前平台只移植只读部分。
- 超星 2026-10-23 明确两个数据接口不涉及 MCP；MCP 为旁路，不是本期前提。

## 实施与验收顺序

1. #1009 核验应用课程库范围、授权、跨课程资料/知识点查询、访问链接和测试材料；缺项记录超星责任方及替代方案，不猜测接口。
2. #1010 实现无选课的课程库定位与可选范围；如采用逐课程方案，需应用目录及适当授权、分页和限额，不依赖学生班级成员身份。
3. #1011/#1012 分别补齐资料、已有知识点查询；指定课程接口可独立复验，全库闭环依赖正式接口能力。
4. #1013 使用实际模型与代表性聊天上下文验收相关性、话题变化、未选修课程来源、访问条件、空结果及失败提示；不验收正文问答。
5. #1006 两条命令复用同一全库查询服务，独立验证确定性目标、幂等、历史及错误反馈；现有显式 ID 模式仅为受限查询/联调。

历史个人课程/MCP/正文问答方案已由本次范围修订取代；既有真实验收记录保留原发生时间和边界，不改写为全库成功证据。本次仅同步规格与 issue，不修改运行时代码或授权发布。
