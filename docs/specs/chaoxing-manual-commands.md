# 超星手动命令增量规格

状态：用户已确认增加手动入口；本分支已实现后端确定性分发、前端菜单登记、查询目标分离与自动化测试。真实超星账号联调仍待外部授权、回调登记和工具映射核验，不能据此宣称真实课程已可查。基础授权与学习能力沿用[主规格](chaoxing-learning.md)。

## 使用体验

保留学习对话中的自动推荐，同时在现有 `/` 菜单增加两条可主动选择、键盘补全和提交的命令。命令名称采用下表，描述与参数提示显示中文。

| 命令 | 菜单说明 | 参数提示 | 查询目标 |
|---|---|---|---|
| `/course-search <关键词>` | 查询超星课程资料 | 例如：`/course-search 梯度下降` | 仅课程资料 |
| `/topic-search <关键词>` | 查询超星已有知识点 | 例如：`/topic-search 导数` | 仅已有知识点 |

- 自动推荐与手动查询是同一能力的两种触发方式；手动命令必须直接执行对应查询，不依赖模型决定是否调用。
- 不先要求学生选课程。默认在本人获授权课程范围内定位资源；已限定会话课程时沿用该范围，命令本身不修改范围。
- 将命令名之后的全部非空文本视为关键词，保留内部空格；仅移除两端空白，长度上限沿用学习查询 schema（当前 1000 字符）。本增量不引入课程 ID、班级 ID、凭证或角色命令行参数。
- 参数缺失或过长时显示中文用法/校验信息，不调用远端；不把缺少参数解释成自动查询全部数据。

## 菜单可见性与失败反馈

- 已登录且部署已配置超星接入时，展示两条命令；不依赖任何 per-user 插件启用位。
- 尚未绑定的学生仍能在菜单发现命令。提交后引导前往账号设置绑定，不发起课程数据请求，不自动跳转或代替学生授权。
- MCP 映射缺失、资料/知识点目标未配置、授权失效、无权限或网络异常时，准确展示对应限制；不能回退到另一个查询目标并伪装成功。
- 部署未配置超星时，菜单不提供可执行的超星入口；用户手工输入命令时后端仍明确返回未配置提示，不能当作未知自然语言交给模型自由解释。
- 只有真实成功完成目标查询后才展示查询结果；0 命中明确说明未找到，未知完整性和达到上限时提示限制。

## 后端分发与复用

- 复用平台已有命令解析、目录展示、输入补全、会话认证、消息幂等、并发/中断门禁、run 生命周期及历史结果展示机制，扩展内置能力命令的登记和分发。只增加前端菜单或只向模型注入一段提示词均不满足验收。
- 学习命令属于内置能力命令，不作为用户需要启用的插件；在命令注册与保留名校验中处理名称冲突，避免插件同名覆盖。
- 入口统一调用学习领域服务；后端从可信平台用户身份、会话和当次 run 范围取得授权及课程上下文。命令参数不能覆盖 owner、令牌或班级身份。
- 查询服务与工具 schema 增加查询目标：`all`、`resources`、`topics`。自然语言路径缺省 `all`，资料命令固定 `resources`，知识点命令固定 `topics`。同一目标贯穿命令、服务和远端适配层。
- 仅校验和调用本次目标必需的已配置能力：资料命令不调用知识点工具，知识点命令不调用资料检索/正文读取工具；共有的课程发现和授权检查可以复用。不能执行完全部远端查询后仅过滤返回结果。
- 复用资料技能包适配出的分页、文件夹过滤、零命中处理及展示上限；知识点命令复用只读树查询，未找到即说明结果，不恢复自动创建分支。
- 可使用现有学习查询接口和同一工具面扩展目标字段；无需增加专供命令绕过权限的 REST 端点，也不引入新的 Python 执行或 SKILL.md 加载机制。
- 用户原始命令进入既有消息与历史语义，同一 clientKey 重放复用既有结果，不重复查询。工具名、执行记录和最终结果应能与触发命令对应；不引入独立且无历史记录的前端直连请求。

## 结果展示

- 在现有对话结果区域展示，不要求学生切换到独立功能页。
- 资料查询展示资料名称、ID、所属课程及真实可访问链接；取得正文时可据此说明相关性，未取得时明确仅为目录结果。没有链接时说明缺失，不能构造未经验证的地址。
- 知识点查询展示已有知识点名称、ID、所属课程，以及接口确实提供的层级、说明或链接；不把知识点 ID 当作课程内容证据。
- 命令执行后，用户可继续自然语言学习，自动推荐仍可工作；显式课程范围与历史来源归属保持主规格的语义。

## 验收与测试边界

沿用已确认的平台 API/Agent 工具入口、真实临时数据库和外部超星传输替身，不为每条命令复制一套测试或执行服务。

- [ ] 超星已配置时，两条命令出现在 `/` 菜单，支持名称过滤、鼠标选择与键盘补全，并显示中文说明和用法。
- [ ] 无插件启用记录、尚未绑定时仍可发现命令；未绑定提交给出设置入口，远端未收到请求。
- [ ] 命令参数缺失/超长被拒绝；合法的含空格中文关键词完整传入统一查询 schema。
- [ ] 从消息 API 提交每条命令，都确定性执行对应目标；测试验证远端被调用的工具名称，而不只验证展示结果经过过滤。
- [ ] 单独配置资料或知识点能力时，对应命令可运行；另一目标的映射缺失不阻断已配置的目标。
- [ ] 默认不选课程即可查询；已有会话范围被沿用；跨用户课程和会话仍拒绝访问。
- [ ] 同 clientKey 重放不重复执行；既有在飞、中断、取消和配额门禁继续生效。
- [ ] 成功结果、0 命中、无权限、能力未配置、网络错误、正文/链接缺失均有准确反馈和历史记录。
- [ ] 知识点不存在时不创建；任何入口均不暴露或调用创建工具。
- [ ] 自然语言自动推荐原有路径回归通过，既有 `/new`、`/compact`、`/model` 及插件命令不受影响。
- [ ] 真实超星联调分别验证两条命令；未完成回调登记、授权及工具映射时，标记外部依赖未满足，不宣称已经可查真实课程。

## 交付边界

平台侧实现与审查修复见 [PR #1005](https://github.com/ACautomata/researcher-service/pull/1005)，对应 [#1006](https://github.com/ACautomata/researcher-service/issues/1006)。真实超星数据联调仍需单独验收。

- 手动查询不调用模型；后续普通对话将尚未入图的命令及展示结果作为正常对话消息送入模型，稳定消息 ID 避免重复追加，已归档记录不再注入。
- 查询失败原因经领域服务脱敏后进入回复正文及工具详情，刷新历史与实时结果一致；取消保留取消提示与 aborted 终态。
- 手动查询沿用本轮启动时读取的课程范围快照，运行期间的范围变更仅影响后续轮次。
