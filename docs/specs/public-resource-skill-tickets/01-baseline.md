## What to build

在全新开发环境按仓库说明启动服务，启用技能后通过对话完成自动及显式检索，并能在历史中找到结果。整理现有首版，不重新实现已有功能。

## Acceptance criteria

- [ ] 将内部 SearXNG 服务、可追溯镜像版本、JSON 配置、网络与部署开关纳入可复现配置；无需宿主公开搜索端口。
- [ ] 新环境具有明确模型连接前置配置；日志与文档不泄露密钥；禁用检索开关时返回明确不可用状态。
- [ ] 从认证会话入口验证自然语言工具调用、命令直达、账号禁用、新运行快照及历史结果；仅替换外部检索/模型传输。
- [ ] 保留已实现的查询校验、URL 安全、部分结果提示及未知标签隐藏；相关服务端检查、卡片测试和前端构建通过。
- [ ] 记录真实模型和自建检索烟测步骤、当前不足及关闭能力的操作；不将本地代码标为线上已交付。
