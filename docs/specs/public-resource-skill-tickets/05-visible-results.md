# 05：对话内直接展示检索结果

评审草案，尚未创建 GitHub issue。

当前状态：部分实现；结果需两次展开，类型/来源和隐藏未知信息已实现。

## What to build

显式搜索完成后用户能直接看到并打开结果；自动调用也能在对话中方便查看，执行细节继续可折叠。

## Acceptance criteria

- [ ] 无需依次展开执行过程和工具卡才能看到显式命令结果；不新增独立导航、页面或平行结果请求。
- [ ] 通过既有工具投影呈现友好名称、真实标题、类型、来源与可点击原链接；实时和历史使用同一结果数据。
- [ ] 不显示未知/待核验/未采集信息，包括脚注与提示气泡；保留真实 partial、空结果、失败与运行中状态。
- [ ] 避免自动回答与结果卡重复堆叠同组链接；有限宽度下标题与来源清晰可用。
- [ ] 用会话及卡片测试验证直接可见、安全链接、部分成功和历史回放，完成本地浏览器演示。
