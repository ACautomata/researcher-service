# 03：权威资料优先及来源可追溯

评审草案，尚未创建 GitHub issue。

当前状态：部分实现；只有三个登记主机优先排序。

## What to build

用户搜索学习问题时，优先获得主题相关且能说明发布主体依据的官方文档、大学课程或教材机构资料，同时保留有用的普通来源。

## Acceptance criteria

- [ ] 建立可维护的来源登记，包含发布主体、适用主题、核对依据与日期；不得把平台或大学域名直接等同于具体内容权威。
- [ ] 在请求预算内进行必要的主题/来源定向召回，按相关性与发布主体证据排序、合并去重；不只调整原列表顺序。
- [ ] 结果保留原始链接及真实站点；作者或转载信息仅在有依据时展示，不显示未知占位。
- [ ] 用固定中文问题对照现有基线，记录新增权威命中及无命中原因；Vue 官方和贝叶斯失败样本均纳入。
- [ ] 通过会话链路证明排序与显示一致，并覆盖冒充主机、无匹配来源及上游部分失败。
