## What to build

## Acceptance criteria

- [ ] 先复现或定位现有实时更新异常并记录证据；不能仅因后续请求成功就宣称修复。
- [ ] 通过既有事件和持久化投影恢复结果，不为本技能新增轮询协议。
- [ ] 覆盖断线重连、刷新、完成事件遗漏和重启中断；不重复展示卡片或因重放再发一次搜索。
- [ ] 取消、失败与成功终态一致；恢复后保留真实原始链接及部分来源状态。
- [ ] 提供可重复的集成测试和浏览器验证记录；若根因在通用会话链路，修复兼容既有其他工具。
