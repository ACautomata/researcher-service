## What to build

对已登记、公开可读的文档，智能体能够读取有界正文并给出与实际内容对应的引用；读取失败仍可返回资源链接。

## Acceptance criteria

- [ ] 范围仅限允许来源的公开文档；不包含视频转写、登录内容、付费墙或全网全文索引。
- [ ] 正文读取有时间、字节、格式和请求预算限制；校验目标与重定向及解析后的地址，拒绝私网地址和来源绕过。
- [ ] 网页内容作为不可信数据，引用必须对应实际读取段落，并标明原页；标题摘要不能冒充正文。
- [ ] 读取失败明确降级为链接结果；不损坏已有纯检索入口及首版发布。
- [ ] 从学习问题到检索、读取、引用及历史结果完成闭环测试，覆盖来源拒绝、内容过长及读取失败。
