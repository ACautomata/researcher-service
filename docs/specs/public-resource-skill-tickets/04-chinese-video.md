# 04：中文视频定向召回与主题匹配

评审草案，尚未创建 GitHub issue。

当前状态：部分实现；能找到 B 站候选，但覆盖不稳定且没有自动语言/热度核验。

## What to build

用户提出中文学习问题时，检索能有针对性地补充中文视频候选，并避免将作者名关键词或平台名误当作内容匹配证据。

## Acceptance criteria

- [ ] 在共享预算内开展面向 B 站等公开可访问视频来源的定向查询，与资料结果合并去重。
- [ ] 记录标题、主题及可取得的作者/语言依据；中文标题不自动证明中文音频，查询包含某教师名不自动认定结果为其课程。
- [ ] 没有相关视频则不凑数；不抓取未授权接口、不绕过验证码、不暗用付费接口。
- [ ] 贝叶斯及特征值等固定问题进行前后对照，报告中文候选覆盖、相关性及代表链接的实际播放情况。
- [ ] 会话卡片可打开真实视频链接；没有热度依据时不出现热门或未知热度标记。
