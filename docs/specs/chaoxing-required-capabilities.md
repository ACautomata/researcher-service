# 超星需补充的接口能力清单

2026-10-24 目标（用户两次澄清后定稿）：面向**学生对话式自主学习**——智能体根据聊天上下文自动推送课程资料、已有知识点与课程链接；**检索范围不限定学生已选课程，需覆盖可公开查阅的课程**。学生在修课程范围作为分阶段交付的第一步（上游接口未齐前的过渡基线），不是最终边界。正文问答本期不做。主规格见 [chaoxing-learning.md](chaoxing-learning.md)。本清单是待对方确认的能力需求，不代表对方已经提供接口或授权。

## 必需能力（完整目标）

| 能力 | 希望超星提供的契约/字段 | 当前缺口及验收方式 |
|---|---|---|
| 公共课程可查阅范围 | 二选一：①跨课程检索接口（关键词查询，不传 courseId/classId）；②应用开放课程目录（含"公共/开放课程"界定、完整分页）＋授权应用查询学生未选修课程 | 未提供。现有两接口均要求 courseId（资料还要求班级 ID），无法触达未选修课程。验收：一门已选修、一门未选修但公共开放、一门未开放课程，核验允许/拒绝边界 |
| 学生课程/选课关系发现 | 读取学生本人课程列表：课程 ID/名称、班级 ID、教师/学期等身份字段；分页与更新时机 | 未提供。支撑"在修课程优先"推荐与过渡期课程档案；需以真实选课变化核验更新语义 |
| 已有知识点学生/应用查询 | topic-list 对学生或应用凭证开放；关键词、稳定知识点 ID、名称、父子层级；如有说明、关联资料一并返回 | 2026-10-24 定案：学生 OAuth token 调用返回 HTTP 200 但业务层拒绝（business_rejected），换关键词/换课程结果一致，强烈指向教师权限模型。请明确权限模型并给成功示例；只读，不使用 addtopic |
| 推荐结果访问入口 | 资料/知识点详情页实际链接，登录方式、有效期，以及公开/需登录/需选修/受限等访问条件；未选修公共课程的阅读条件必须明确 | 当前无可访问链接成功证据。用真实用户打开代表性链接（含未选修课程），检索权限与阅读权限分别记录；未知状态不能标成可直接阅读 |
| 元数据与相关性依据 | 资料简介/摘要、课程简介、知识点说明、关联资料；明确可用字段和缺失语义 | 建议提供以提高推荐准确度；仅标题也可做初步推荐，但必须标注依据有限。摘要/说明不等于正文问答 |
| 稳定接口与运营约束 | 方法、真实 URL、请求/响应 schema、鉴权示例、错误码、分页、超时、QPS/日配额、版本/变更/下架规则 | 给出脱敏请求响应、成功/空结果/无权限示例和获授权测试数据；秘密通过安全渠道配置，不进入仓库/issue |

## 分阶段交付说明

分阶段是**交付顺序，不是功能取舍**：第一阶段平台以学生课程档案（在修课程）跑通对话自动推送体验（资料目标现已真实可用）；公共课程范围与知识点数据源随上游开放即接入，不留平台侧前置依赖。

## 本期不需要对方为此交付

- 知识点新建/修改、题库写接口。
- 课件正文下载、PDF/Office/OCR、基于正文的问答接口；可列未来能力，不作为本期阻塞。
- MCP 初始化或工具目录：2026-10-24 复测 OAuth 用户 token 初始化仍 403，超星已明示两数据接口"不涉及 MCP"；按 HTTP-only 处理，不因 MCP 历史 403 判定 HTTP 失败，也不再等待 MCP 开放。

## 当前已知证据（2026-10-24 复测）

- 资料：学生本人 OAuth 在指定 courseId/classId 下检索成功，10-23 与 10-24 两次真实成功记录（返回真实资料目录）；未证明未选修课程、摘要或链接可用。
- 知识点：学生 token 业务层拒绝定案（多关键词/多课程一致）；教师权限假设最强，可由自建教师课程实验或上游确认收口。
- MCP：OAuth 用户 token 初始化 403（10-24 复测，拒绝特征未命中已知类别）；按 HTTP-only 处理。
- scope：原 mooc:resource / mooc:qbank 绑定成功；statistic:studyai:read 曾授权失败，不盲换 scope。

## 可发送给超星的需求（2026-10-24 终版）

我们的产品面向学生对话式自主学习：学生在对话中讨论学习问题时，智能体根据上下文自动推送相关课程的资料、已有知识点与课程链接。**检索范围不限定学生已选课程，需覆盖可公开查阅的课程。**现有两个 HTTP 接口我们已实测：`searchCourseDataJson` 用学生 OAuth token 调用成功并返回真实资料目录；`topic-list` 用同一 token、同一课程返回 HTTP 200 但业务拒绝（`status:false`）。

请协助确认：

1. `topic-list` 是否要求教师权限？学生凭证或应用级凭证能否查询已有知识点？如支持请给出成功示例；
2. 公共课程查阅方案：能否提供跨课程检索接口（不传课程/班级 ID），或开放课程目录＋授权查询学生未选修的课程？"公共/开放课程"的界定与边界是什么？
3. 是否提供学生课程/选课关系发现接口（读取学生本人课程列表，含课程/班级 ID），支撑"在修课程优先"的推荐；
4. 推荐结果的访问链接契约：实际链接、登录方式、有效期与访问条件，特别是未选修公共课程学生能否打开阅读；
5. 两个接口的运营约束：错误码、分页、超时、QPS/日配额与变更规则。

另：`/openai/studyai/data`（MCP）用 OAuth 用户 token 初始化始终 403，请确认该端点是否未对本应用开放，我们按 HTTP-only 处理即可。
