# 本人课程同步与关键词跨课程查询

2026-10-26 用户要求：把已验证的网页课程清单提取方式接入平台，保存后只输入关键词即可搜索，不再每次手填课程和班级 ID；测试后发布上线。

## 使用流程

1. 在账号设置绑定本人超星账号，将“同步我的超星课程”工具拖到浏览器书签栏。
2. 从设置页打开超星“我学的课”，登录后点击该同步书签。
3. 工具读取当前页面可见课程的名称、课程和班级 ID，经平台设置页 URL fragment 交付；页面立即清除 fragment，展示预览。本人点击“确认同步”后才写入。
4. 可通过课程清单 JSON 文件或粘贴已有清单补充导入。导入前端只提取课程元数据，不转发原文件其他字段。每次确认替换现有清单，最多 100 个课程/班级；支持清除。
5. 对话中输入 `/course-search 可视化`；后台在已同步清单中查询并显示课程名称与“前往课程资料”链接。可用既有课程范围控件限定单门课程。

本功能属于首次网页同步后保存课程清单，不是 OAuth 绑定自动发现。课程增加、退课或另行归档后需重新同步/整理；不宣称网页当前可见清单是全量实时课程库。

## 数据与接口

- `PUT /api/v1/integrations/chaoxing/courses`：`{courses:[{id,classId,name}]}`；空数组清除。经全局 zod schema 验证，数字 ID、名称长度、总数和重复课程/班级组合均有限制。owner 从平台认证取得，客户端不能覆盖。
- `GET /courses` 返回本人保存的清单及 `syncedAt`。未同步的 HTTP 模式返回空列表，不试探未知课程列表 API；显式 MCP 模式保留既有目录能力。
- SQLite v16→v17 为 `chaoxing_bindings` 添加 nullable `coursesJson` 和 `coursesSyncedAt` 两列；启动期幂等升级，不改写已有凭证。课程清单随绑定按用户隔离，重新授权成功、解绑、401/授权失效时清除，避免跨超星身份复用。同步采用绑定代次条件更新，不能跨越在飞解绑/重新授权。
- 清单不是访问凭据；每门课程仍使用本人 OAuth token 请求原资料 API，由超星验证成员权限。不读取、传送或保存超星网页 Cookie、密码、个人签名。

## 查询行为

- 没有显式课程参数时使用清单；已限定课程但未传班级时，从清单补齐班级。同一课程多班级逐个查询，资料按课程和资源 ID 去重；跨课程同 ID 不合并。
- 一次查询固定清单快照，最多 3 个并发，45 秒总时限，最多展示 50 条。每课程沿用资料分页、文件夹过滤及零命中核对流程。
- 部分课程失败保留其他成功结果，并注明失败课程与不完整；全部失败返回错误，不能冒充零命中。401 保持原绑定失效处理；用户取消不返回成功结果。达到时间或展示上限明确说明不完整。
- 自然语言工具默认使用同步清单，未同步时引导账号设置。手动命令仍确定性执行，不依赖模型；显式课程/班级参数保留兼容。
- 原有资料入口链接、浏览器超星登录及本人课程权限条件保持不变；清单课程名称仅为用户导入的元数据，不能作为课件正文证据。

## 验证

新增真实临时数据库/HTTP 替身验证：按用户持久化与隔离、严格输入、仅关键词跨课程查询、名称和链接归属、课程范围、部分/全部失败、401、重新绑定/解绑清单清理；消息 API 至历史记录的无 ID 命令闭环。

新增网页同步工具测试：真实生成的书签代码对页面链接提取、去重和敏感参数剥离；fragment 导入先预览不自动写入，确认后保存；无效输入和失败保留预览。增量数据库测试验证旧绑定凭证保留及两次升级幂等。并发、取消和总时限单独受控验证。

发布后需以本人真实课程同步及仅关键词查询验收，不能用本地替身测试代替线上超星访问证明。
