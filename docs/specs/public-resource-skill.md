# 公开资源检索技能规格

状态：规格整理于 2026-10-27；2026-11-02 已合并发布到 GitHub #1027。现有代码及验证均在隔离本地环境，尚未合并、发布或部署正式线上。

## Problem Statement

学生提出具体学习问题时，需要可信的原始资料和容易理解的中文视频。现有超星能力受课程成员关系与接口权限限制，无法覆盖公开网络。用户不希望另开搜索页面或购买检索 API，希望智能体适时检索，也能用明确命令直接调用，并在对话里点开资源。

当前首版已能执行检索，但权威资料和中文视频覆盖不稳定，结果藏在两层折叠中，且观察到一次完成结果需刷新才恢复。必须区分“工具执行成功”“资源相关且可信”“链接实际可访问”。

## Solution

在现有对话内提供“公开资源检索”技能，由既有插件机制承载。以解决具体学习问题为主，权威资料打底、中文视频补充，英文官方资源可补充。通过自建 SearXNG 检索公开网页，不接入付费检索 API。

用户启用后，智能体可以在学习问题需要资料时自动调用；用户输入 `/resource-search <问题或关键词>` 则确定性执行同一检索工具。结果提供标题、资料/视频类型、真实来源和原始链接；缺失的热度、核验状态不占据界面。没有相应结果时不凑数，真实的失败、空结果和部分来源不可用仍明确说明。

| 结果真实性 | 未读取正文、字幕；未自动采集热度；提示词禁止推断未读内容 | 更完善的来源溯源；正文证据属于后续独立阶段 |
| 可靠性 | 已有 12 秒超时、取消信号、部分结果标记、安全 URL 和错误收敛 | 缓存、限流、请求预算；一次实时状态未及时更新的根因与恢复验证 |
| 模型连接 | 隔离环境配置修正后，真实试连接及自动检索通过 | 作为首版交付前置配置记录，不计作新增检索能力 |

“已实现”仅指本地代码与已记录证据，不等于已上线或相应 ticket 可以关闭。

## User Stories

1. 作为学生，我希望围绕具体学习问题获取参考资料，以便继续理解和学习。
2. 作为学生，我希望智能体在合适时机自动检索，以便不必每次提醒它搜索。
3. 作为学生，我希望使用 `/resource-search` 显式检索，以便直接获得资源列表。
4. 作为学生，我希望无关闲聊无需检索，以便避免无意义等待。
5. 作为学生，我希望优先看到官方文档、大学课程或有明确发布主体的资料，以便判断依据。
6. 作为学生，我希望有中文讲解视频补充，以便用适合自己的方式学习。
7. 作为学生，我希望英文官方资源可以补充中文结果，以便不遗漏有价值的资料。
8. 作为学生，我希望点击标题进入对应资源原页，以便查看或播放。
9. 作为学生，我希望看到实际站点及有依据的发布主体，以便区分平台与作者。
10. 作为学生，我希望未知热度和待核验标签不显示，以便保持结果简洁。
11. 作为学生，我希望没有视频时如实呈现，以便不被无关结果误导。
12. 作为学生，我希望工具部分失败时仍保留可用结果，以便继续学习。
13. 作为学生，我希望空结果和服务故障能被区分，以便决定换词或稍后重试。
14. 作为学生，我希望取消运行能停止检索，以便控制等待和请求消耗。
15. 作为学生，我希望刷新后仍能看见已完成结果，以便可靠地找回链接。
16. 作为学生，我希望结果不被深藏在执行细节中，以便快速使用。
17. 作为用户，我希望通过插件页启停技能，以便控制账号能力。
18. 作为用户，我希望禁用后新运行不再携带工具和命令，历史结果仍可查看，以便行为可预测。
19. 作为用户，我希望检索不发送账号凭据或私有课程资料，以便只围绕公开学习关键词查找。
20. 作为用户，我希望模型不将搜索摘要当作已读正文或视频证据，以便回答可信。
21. 作为维护者，我希望部署可复现且可关闭检索能力，以便维护和回滚。
22. 作为维护者，我希望请求有预算并记录质量基线，以便控制免费上游的限流影响。

## Implementation Decisions

- 产品称“技能”，实现复用现有插件目录、账号启用状态、运行快照、工具执行、事件及历史投影；不新增平行技能运行时。
- 标识为 `public-resources`，工具为 `public_resource_search`，命令为 `/resource-search`。两个入口共用检索实现；显式命令不由模型决定是否执行。
- 默认不替用户启用。运行开始采集插件快照，启停影响新运行，历史工具结果继续可回放。
- 查询经统一 zod 校验，去除首尾空白后为 1–200 字符；面向公开学习关键词，不主动外送附件、凭证或私有知识库正文。
- 自建 SearXNG 使用内部服务地址和 JSON 响应，不接受用户自定义检索服务器；部署开关和插件启用分别控制服务可用性与账号工具装配。
- 当前只有元数据检索；模型不得把标题/摘要当作已审读正文，不执行页面内容中的指令。当前运行框架仍需有效模型配置；命令直达工具本身不发起模型推理。
- 当前返回最多三条资料和三条视频，按类型交错排列，并遵循工具事件字节预算；不足时照实返回，不保证每次两类俱全。URL 仅允许 HTTP(S)、无用户信息，并去重；前端再次校验可点击链接。
- 来源登记需记录可复核的发布主体依据，不能仅凭大学域名或视频平台认定内容权威；托管站点、实际作者和转载关系应分开判断。未取得字段不展示，不制造权威、中文语言或热门标记。
- 当前卡片仅展示标题、类型、已知来源；不显示“热度未知”“来源待核验”等占位文字，也不迁到脚注或提示气泡。真实 partial、失败与空结果状态保留。
- 扩展定向检索时加入有界调用、重试与缓存策略；完整、部分及失败状态分开，取消传播到上游；不以付费接口暗中兜底。
- 使用既有持久化投影恢复结果，避免为搜索单独建立轮询通道。实时未更新问题先复现定位，再决定修复范围。
- 免费指不购买检索 API，不代表服务器、运维或现有模型推理免费；上游验证码和限流仍可能影响结果。

## Testing Decisions

- 拟采用一个主要集成边界：认证会话消息入口 → 运行装配与命令/模型工具调用 → 事件及持久化投影 → 对话结果卡。沿用现有会话、插件与历史回放测试设施，仅替换外部检索和模型传输；账号权限、启停快照、命令分发与存储保持真实。
- 在该边界验证显式命令直达、模型发出工具调用后的处理、禁用不装配、输入拒绝、取消、部分失败、空结果及刷新恢复。模拟模型不能证明真实模型会自发调用，必须单列真实模型烟测。
- 补充必要的检索适配与卡片测试：URL 安全、主机冒充、去重、字节预算、来源字段、未知标签缺席，以及故障提示仍存在；不测试私有函数形状。
- 已有先例为插件注册/会话表面测试、检索工具适配测试及 Vue 卡片测试。现有测试尚不等于上述完整会话链路已经覆盖。
- 质量验收使用固定中文公开学习问题集，覆盖数学、计算机和自然科学，同时测试自动提问、显式命令、无关闲聊。逐项记录权威来源依据、主题相关性、中文视频候选、链接可达性、耗时和部分失败。
- 先保留现有四次请求为基线，新增至少十二个多主题问题形成可重复对照；对照改进前后结果，不预设无证据的成功率承诺。链路成功率与资源质量分别统计。
- 对代表资料实际打开正文核对主题，对代表视频实际打开播放器核对可播放状态；未听读全篇不声明内容正确或音频语言已经核验。
- 首版上线前在目标部署网络重做烟测并记录版本、配置和回滚步骤；本地成功不能替代目标环境验收。

## Out of Scope

- 独立公开资源导航、独立搜索页面、绕开现有会话链路的搜索 API。
- 付费检索 API、绕过登录/验证码/付费墙、私有超星内容抓取。
- 首版中的全文索引、视频下载/转写、自动热度采集、无依据的权威或热门背书。
- 首版中基于未读取内容生成逐段证据引用；公开文档正文读取仅列为非阻塞后续候选。
- 承诺全网覆盖、每次均有权威资料和中文视频，或免费上游无限稳定。
